Bulong

Bluetooth messenger: chat with people around you with no internet and no signal. Phones pass messages along to each other.

Download Bulong (Android)
  1. Tap Download and open the file.
  2. If Android asks, allow Install unknown apps for your browser.
  3. Open Bulong, type your name, allow Nearby devices. Done!
